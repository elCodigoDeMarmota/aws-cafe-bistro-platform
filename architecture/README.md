# ☕ AWS Café Bistro Platform

Proyecto desarrollado como parte de mi formación en AWS re/Start.

## 📖 Descripción

AWS Café Bistro Platform es un proyecto de computación en la nube que simula la transformación digital de una cafetería y panadería.

El proyecto evoluciona desde un sitio web estático alojado en Amazon S3 hasta una solución capaz de recibir pedidos en línea, gestionar clientes y aplicar buenas prácticas de seguridad, monitoreo y escalabilidad utilizando servicios de AWS.

El objetivo es demostrar habilidades prácticas en arquitectura cloud, administración de infraestructura, seguridad, redes y automatización mediante escenarios reales de negocio.

---

## 🎯 Objetivos

- Implementar un sitio web estático utilizando Amazon S3.
- Desplegar una aplicación web en Amazon EC2.
- Aplicar buenas prácticas de seguridad con IAM y Security Groups.
- Administrar recursos mediante AWS CLI.
- Implementar almacenamiento de datos para pedidos y clientes.
- Supervisar recursos mediante herramientas de monitoreo.
- Diseñar una arquitectura escalable y de alta disponibilidad.

---

## 🛠️ Servicios AWS Utilizados

- Amazon S3
- Amazon EC2
- AWS IAM
- Security Groups
- Elastic IP
- AWS CLI
- Amazon DynamoDB
- Amazon CloudWatch
- AWS CloudTrail
- AWS Systems Manager
- Elastic Load Balancer
- Auto Scaling
- Amazon Route 53
